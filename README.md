# Little Office Game

A free browser office simulation with five workers, five computers, Pip the cat, a garden, a gym and local mini games.

**[Play Little Office Game](https://tamerlanmajidov5-cmd.github.io/little-office/)**

[Little Office homepage](https://tamerlanmajidov5-cmd.github.io/)

Explore the room, control the workers and play chess, tic-tac-toe, memory, Toto's Star Quest and other mini games. The guest office opens in your browser without an app download or account.

This repository contains the public homepage. The game files are in the [little-office repository](https://github.com/tamerlanmajidov5-cmd/little-office).

The shared game has no connected live AI service. It does not provide access to the creator's chats or account.
